# ozon-seller-mcp

MCP-сервер для [Ozon Seller API](https://docs.ozon.ru/api/seller). Даёт Claude доступ к кабинету продавца: каталог, цены, остатки, аналитика, финансы, отправления — 29 инструментов.

Внутри лежит и самостоятельный Go-клиент Seller API (`ozon/`) — его можно использовать отдельно от MCP.

**Записывать данные сервер по умолчанию не может.** Режим только для чтения включён из коробки, доступ на изменение открывается переменной окружения. Это осознанное решение: сервер отдаёт языковой модели доступ к живому магазину, и включать запись должен человек в конфигурации, а не удачная формулировка в переписке.

## Два способа запуска

| | stdio | Streamable HTTP |
|---|---|---|
| Где живёт | на вашей машине, Claude запускает подпроцессом | на сервере |
| Устройства | только эта машина | все, включая телефон |
| Ключ Ozon | на каждой машине | в одном месте |
| Права | `OZON_ALLOW_WRITES` | определяются токеном запроса |

Сетевой режим описан в [`docs/REMOTE.md`](docs/REMOTE.md). Коротко: `--http :8571`, два токена (читающий и пишущий), обратный прокси с TLS.

## Установка

```bash
go install github.com/MainAlexStark/ozon-seller-mcp/cmd/ozon-seller-mcp@latest
```

Проверьте ключи до того, как прописывать сервер в Claude — отлаживать молчащий MCP внутри клиента неприятно:

```bash
OZON_CLIENT_ID=... OZON_API_KEY=... ozon-seller-mcp --check
```

Ключ выпускается в кабинете продавца: **Настройки → API-ключи**.

> С сентября 2026 новые ключи выпускаются на 3 месяца. Если сервер внезапно перестал авторизовываться — скорее всего истёк ключ, а не сломался код.

## Подключение к Claude Code

```bash
claude mcp add ozon \
  -e OZON_CLIENT_ID=ваш-id \
  -e OZON_API_KEY=ваш-ключ \
  -- ozon-seller-mcp
```

## Подключение к Claude Desktop

`~/Library/Application Support/Claude/claude_desktop_config.json` (macOS) или `%APPDATA%\Claude\claude_desktop_config.json` (Windows):

```json
{
  "mcpServers": {
    "ozon": {
      "command": "ozon-seller-mcp",
      "env": {
        "OZON_CLIENT_ID": "ваш-id",
        "OZON_API_KEY": "ваш-ключ"
      }
    }
  }
}
```

Перезапустите Claude. Спросите «покажи статус подключения к Ozon» — сервер ответит через `ozon_status`.

## Настройки

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `OZON_CLIENT_ID` | — | Обязательно |
| `OZON_API_KEY` | — | Обязательно |
| `OZON_ALLOW_WRITES` | `false` | stdio: `true` разрешает изменять данные |
| `OZON_HTTP_ADDR` | — | сеть: адрес прослушивания, например `127.0.0.1:8571` |
| `OZON_TOKEN_READ` | — | сеть: токен только на чтение |
| `OZON_TOKEN_WRITE` | — | сеть: токен на чтение и запись |
| `OZON_ALLOWED_ORIGINS` | — | сеть: разрешённые `Origin` через запятую |
| `OZON_MAX_PRICE_DELTA` | `30` | Порог изменения цены в процентах |
| `OZON_MAX_ITEMS_PER_WRITE` | `100` | Позиций за один вызов записи |
| `OZON_MAX_RESPONSE_BYTES` | `120000` | Потолок размера ответа инструмента |
| `OZON_BASE_URL` | боевой хост | Подмена для тестов |

## Четыре заслона на пути опасных действий

**0. Права — свойство подключения, а не процесса.** В сетевом режиме режим доступа определяется токеном запроса. Устройство с читающим токеном физически не может выполнить запись: проверка стоит в обработке каждого запроса. Телефон получает читающий токен, пишущий живёт только там, где вы действительно правите магазин. Если пишущий токен не задан вообще — изменить магазин через сеть нельзя ничем.

**1. Чтение по умолчанию.** Инструменты, помеченные как изменяющие данные, в обычном режиме отказываются работать и объясняют, как включить запись. Пока `OZON_ALLOW_WRITES` не выставлен, максимум, что может случиться, — лишний запрос на чтение.

**2. Страховка от потерянного нуля.** Перед изменением цен сервер читает текущие и сравнивает. Смена 6900 → 690 проходит любую проверку формата и молча уничтожает маржу: Ozon такую цену примет без возражений. Поэтому изменение больше 30 % останавливается и требует `confirm_large_change: true`.

```
Изменение цены больше чем на 30% — запись остановлена.

Чаще всего это опечатка в порядке величины (690 вместо 6900),
и она уничтожает маржу молча: Ozon примет такую цену без возражений.

  pp-mw-1234               6900.00 → 690.00  (90%)

Если изменение верное, повторите вызов с confirm_large_change: true.
```

Если текущие цены прочитать не удалось, запись не блокируется — иначе временный сбой парализовал бы работу, — но в ответ добавляется предупреждение, что проверка не сработала.

**3. Ограничение размера ответа.** Ответ на несколько мегабайт не «просто длинный»: он вытесняет из контекста задачу, ради которой вызывался. Такие ответы обрезаются с подсказкой, как сузить выборку.

## Про версии методов Ozon

Ozon отключает старые версии методов по расписанию, и это главный источник поломок у любого клиента. Учтено:

- все пути собраны в одном файле — [`ozon/paths.go`](ozon/paths.go) — с историей переездов в комментарии;
- `ozon_api_selftest` прогоняет по одному минимальному запросу к каждому read-методу и показывает, какие отвечают, а какие нет;
- на HTTP 404 сервер сам подсказывает, что версия, вероятно, отключена.

Актуальные на сентябрь 2026 переезды уже применены: `/v5/product/info/prices`, `/v4/product/info/stocks`, `/v3/product/list`, `/v4/product/info/attributes`, `/v3/product/info/list`, `/v2/product/pictures/info`. Отключённый `/v3/finance/transaction/list` заменён тремя методами `/v1/finance/accrual/*` — у них окно запроса ограничено месяцем, и сервер проверяет это до отправки.

## Устройство

Разделение, которое стоит понимать при доработке:

- **Чтение** идёт через `Client.Call` и возвращает сырой JSON. Ozon регулярно добавляет поля в ответы; жёсткие структуры на чтении означали бы терять новые данные и чинить клиент после каждого обновления.
- **Запись** типизирована строго и валидируется до отправки. Здесь цена ошибки — испорченные карточки в живом магазине.

Добавить новый read-метод — несколько строк в `internal/tools`:

```go
r.Add(Spec{
    Name:   "ozon_new_thing",
    Path:   ozon.PathNewThing,
    Desc:   "Что делает и когда пригодится.",
    Schema: schema(obj{"limit": num("Сколько записей")}),
})
```

## Разработка

```bash
go test ./...       # тесты, включая сквозные против подставного Ozon
go build ./...
make check          # vet + gofmt + тесты
```

Отдельно проверяется, что читающий токен не может писать, — это центральная гарантия сетевого режима (`internal/httpx/server_test.go`).

Сквозные тесты поднимают подставной Seller API и прогоняют весь путь: вызов инструмента → защита → клиент → HTTP. Страховка от опечатки в цене проверяется именно так — с фиктивной текущей ценой 6900 и попыткой записать 690.
