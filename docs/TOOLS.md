# Инструменты

38 инструментов. Помеченные **ЗАПИСЬ** изменяют данные в магазине и работают только при `OZON_ALLOW_WRITES=true`.

## Диагностика

Начинайте отсюда, когда что-то не работает.

| Инструмент | Что делает |
|---|---|
| `ozon_status` | Режим сервера, пороги защиты, кабинет продавца. Отвечает на вопрос «почему он отказывается менять цену» |
| `ozon_api_selftest` | По одному минимальному запросу к каждому read-методу. Показывает, какие живы, а какие Ozon отключил |

## Категории

Без `description_category_id` и `type_id` товар не создать — начинать всегда отсюда.

| Инструмент | Что делает |
|---|---|
| `ozon_category_tree` | Дерево категорий и типов товара |
| `ozon_category_attributes` | Характеристики категории: какие обязательны, какие словарные |
| `ozon_category_attribute_values` | Допустимые значения словарной характеристики |

Когда импорт падает с ошибкой валидации — почти всегда это незаполненная обязательная характеристика. Смотрите `ozon_category_attributes` для нужной категории.

## Каталог

| Инструмент | Что делает |
|---|---|
| `ozon_product_list` | Список товаров с фильтрами по видимости и артикулам |
| `ozon_product_info` | Подробности: название, категория, статусы, изображения, штрихкоды |
| `ozon_product_attributes` | Заполненные характеристики товаров |
| `ozon_product_pictures` | Изображения карточек и статус загрузки |
| `ozon_content_rating` | Контент-рейтинг и что именно снижает балл |
| `ozon_warehouse_list` | Склады продавца; `warehouse_id` нужен для остатков |
| `ozon_product_import` | **ЗАПИСЬ** Создать или обновить карточки |
| `ozon_import_status` | Статус задачи импорта; с `wait=true` дожидается результата |
| `ozon_product_update_attributes` | **ЗАПИСЬ** Обновить характеристики |
| `ozon_pictures_import` | **ЗАПИСЬ** Загрузить изображения по URL |
| `ozon_product_visibility_set` | **ЗАПИСЬ** Показать или скрыть товары |

Импорт асинхронный. Ответ `ozon_product_import` означает «задача принята», а не «товар создан»: реальный результат приходит только из `ozon_import_status`. Поэтому у него есть `wait=true` — с ним вы сразу увидите ошибки валидации.

## Цены и остатки

| Инструмент | Что делает |
|---|---|
| `ozon_prices_info` | Цены вместе с комиссиями и тарифами логистики |
| `ozon_stocks_info` | Остатки: сколько на складах, сколько в резерве |
| `ozon_stocks_by_warehouse` | Остатки FBS в разрезе складов. Нужен список `sku` или `offer_id` |
| `ozon_prices_update` | **ЗАПИСЬ** Изменить цены; со страховкой от опечатки |
| `ozon_stocks_update` | **ЗАПИСЬ** Изменить остатки; `stock: 0` снимает с продажи |

`ozon_prices_info` — единственный способ узнать реальную выплату по товару. Считать маржу по одной цене витрины бессмысленно: комиссия и логистика съедают заметную часть.

У `ozon_prices_update` есть аргумент `confirm_large_change`. Он нужен, когда изменение цены выходит за порог (по умолчанию 30 %). Ставьте его только после того, как цену проверил человек — он существует ровно для того, чтобы такое изменение не проходило автоматически.

## Аналитика

| Инструмент | Что делает |
|---|---|
| `ozon_analytics_data` | Метрики продаж с группировкой по товару и дате |
| `ozon_analytics_stocks` | Остатки в реальном времени с оборачиваемостью |

Метрики `ozon_analytics_data`: `revenue`, `ordered_units`, `hits_view`, `hits_tocart`, `conv_tocart`, `returns`, `cancellations`, `position_category`. Группировки: `sku`, `day`, `week`, `month`, `category1`…`category4`.

`ozon_analytics_stocks` свежее, чем `ozon_stocks_info`, и показывает, на сколько дней хватит запаса.

## Финансы

| Инструмент | Что делает |
|---|---|
| `ozon_finance_by_day` | Начисления за один день: выплаты, комиссии, удержания. Без даты — вчера |
| `ozon_finance_postings` | Начисления по конкретным отправлениям: экономика продажи. До 200 номеров за раз |
| `ozon_finance_accrual_types` | Справочник видов начислений |

Эти три метода пришли на смену отключённому `/v3/finance/transaction/list`, но устроены иначе, чем он. **Периода у них нет.** `ozon_finance_by_day` отдаёт начисления за один день — чтобы собрать месяц, его вызывают по дням. `ozon_finance_postings` ищет не по датам, а по номерам отправлений: их берут из `ozon_postings_list` или `ozon_fbo_postings_list`.

## Заказы и отзывы

| Инструмент | Что делает |
|---|---|
| `ozon_postings_list` | Отправления FBS за период: заказы, статусы, дедлайны отгрузки |
| `ozon_posting_get` | Подробности одного отправления |
| `ozon_reviews_list` | Отзывы на товары |

## FBO: заказы и остатки на складах Ozon

Схема, где товар лежит на складе Ozon. Вопрос здесь другой, чем при FBS: не «что отгрузить сегодня», а «что и куда везти заранее».

| Инструмент | Что делает |
|---|---|
| `ozon_fbo_postings_list` | Заказы FBO за период. Без дат берётся последняя неделя; постраничность курсорная |
| `ozon_fbo_posting_get` | Подробности одного заказа FBO |
| `ozon_fbo_stocks` | Остатки в разрезе складов Ozon: свободно, в резерве, в пути |
| `ozon_fbo_clusters` | Кластеры Ozon и склады внутри них |

`ozon_fbo_stocks` отвечает на вопрос, на который сводный остаток ответить не может: ноль в одном кластере не виден, пока в другом лежит запас.

## FBO: поставки

| Инструмент | Что делает |
|---|---|
| `ozon_supply_orders_list` | Заявки на поставку: что вы везёте или собираетесь везти |
| `ozon_supply_order_get` | Подробности заявок: склад, таймслот, статус, состав |
| `ozon_supply_order_items` | Состав поставки по `bundle_id` из предыдущего метода |
| `ozon_supply_orders_counters` | Сводка заявок по статусам — заодно показывает сами названия статусов |
| `ozon_supply_timeslots` | Свободные таймслоты приёмки по заявке |

Все инструменты FBO только читают. Создание поставки — многошаговый сценарий с асинхронными статусами, и цена ошибки в нём измеряется не карточками, а машиной, приехавшей не в тот день; поэтому запись сюда пока не заведена.

Идентификаторы заявок выглядят как числа, а Ozon ждёт строки — сервер приводит тип сам, так что можно передавать и то и другое.

## Типовые сценарии

**«Что продавалось в августе»** — `ozon_analytics_data` с `date_from`/`date_to`, метриками `revenue` и `ordered_units`, группировкой по `sku`.

**«Сколько я реально заработал»** — `ozon_finance_by_day` по дням (метод отдаёт один день за вызов) или `ozon_finance_postings` по конкретным заказам. Цена витрины и выплата — разные числа.

**«Какие карточки недозаполнены»** — `ozon_product_list` → `ozon_content_rating` по полученным SKU. Рейтинг прямо говорит, каких полей не хватает.

**«Что заканчивается»** — `ozon_analytics_stocks`: показывает оборачиваемость, а не только текущий остаток.

**«Подними цену на 10 % по этим артикулам»** — `ozon_prices_info` для текущих цен, затем `ozon_prices_update`. Страховка пропустит: 10 % ниже порога.

**«Создай карточку»** — `ozon_category_tree` → `ozon_category_attributes` для выбранной категории → `ozon_product_import` → `ozon_import_status` с `wait=true`.

**«Что везти на склады Ozon»** — `ozon_fbo_stocks` покажет, где заканчивается, `ozon_fbo_clusters` — куда это везти, `ozon_supply_orders_list` — что уже в пути, чтобы не отправить второй раз.

**«Что с моей поставкой»** — `ozon_supply_orders_counters` для общей картины, затем `ozon_supply_orders_list` с нужным статусом и `ozon_supply_order_get` по идентификатору. Состав — `ozon_supply_order_items` по `bundle_id`.
